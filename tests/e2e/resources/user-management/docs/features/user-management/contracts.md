## BC 内契约

### C-001: 注册
- **接口**: `AuthService.register`
- **业务承诺**: 创建新用户账户并返回认证令牌
- **前置条件**: 邮箱未被注册；密码 >= 8 字符
- **后置条件**: 用户已持久化；令牌已签发
- **失败语义**: 邮箱重复或密码不合规时抛出错误，无副作用
- **幂等性**: 否 — 重复注册同一邮箱会失败

### C-002: 登录
- **接口**: `AuthService.login`
- **业务承诺**: 验证凭据并返回访问令牌
- **前置条件**: 用户存在且状态为 active
- **后置条件**: 令牌已签发
- **失败语义**: 用户不存在、密码错误或状态非 active 时抛出错误
- **幂等性**: 是 — 同一凭据多次登录返回等效令牌
