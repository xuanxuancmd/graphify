# 上下文图 — User Management System

## 1. 限界上下文

| BC ID | BC 名称 | 分类 | 代码根 | 职责（一句话业务定义） |
|-------|---------|------|--------|----------------------|
| BC-01 | 用户管理 | 核心域 | `src/models`, `src/repositories`, `src/services` | 管理用户身份、档案与生命周期 |
| BC-02 | 认证 | 支撑域 | `src/auth`, `src/middleware` | 提供注册、登录与令牌管理 |

## 2. 业务关系

| 从 | 到 | 关系类型 | 同步/异步 | OHS 实现 | 业务含义 |
|------|----|---------|:---------:|---------|---------|
| BC-02 | BC-01 | 客户-供应商 | 同步 | — | 认证依赖用户管理的用户查询与持久化承诺 |
| BC-02 | 外部 | OHS | 同步 | `POST /auth/register`, `POST /auth/login`, `POST /auth/refresh` | 对外暴露注册、登录、令牌刷新端点 |

### 2.1 对外契约文件清单

| BC | 契约类型 | 协议 | 文件路径 |
|----|---------|------|---------|
| BC-02 | REST | HTTP | `src/auth/auth.controller.ts` |

## 3. 统一语言

| 术语 | 定义 | 跨 BC 歧义？ |
|------|------|:-----------:|
| 用户 | 系统中的注册身份，含邮箱、密码哈希、档案和状态 | 无 |
| 档案 | 用户的展示信息：昵称、头像、简介 | 无 |
| 认证 | 验证用户身份并签发访问令牌的过程 | 无 |
| 令牌 | JWT 格式的访问凭证，携带用户 ID 和邮箱 | 无 |
| 挂起 | 管理员操作：冻结用户登录和 API 访问权限 | 无 |
| 软删除 | 标记用户为已删除但保留记录供审计 | 无 |

## 4. 领域愿景声明

本系统交付用户身份管理的核心能力——从注册到生命周期的完整管理。用户管理（BC-01）是核心交付者，认证（BC-02）为支撑域，通过 JWT 令牌机制为用户管理提供访问安全保障。
